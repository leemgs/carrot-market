🥕 당근마켓 신규 매물 알림

원하는 제품 키워드와 구매 지역을 등록하세요.
조건에 맞는 새 매물이 올라오면 이메일로 바로 알려드립니다.

어떻게 동작하나요?

  1. 키워드·지역·이메일을 입력해 감시 항목을 만듭니다.
  2. GitHub Actions가 15분마다 당근마켓을 검색합니다.
  3. 조건(제목에 키워드 포함 + 해당 지역)에 맞는 신규 매물을 찾으면
  4. Google SMTP(Gmail)로 매물 정보와 구매 링크를 이메일로 보냅니다.
  5. 모바일에서 링크를 눌러 빠르게 구매 문의하세요!

감시 항목 만들기

1. 아래 감시 설정을 복사하세요

이 내용을 저장소의 config/watches.json 안 watches 배열에 추가하면 됩니다.

2. 저장소에 반영하기

아래 버튼을 누르면 GitHub 편집 화면이 열립니다. watches 배열에 위 내용을 붙여넣고 커밋하세요.

GitHub에서 config/watches.json 편집 →

3. (최초 1회) Gmail 시크릿 등록

저장소 Settings → Secrets and variables → Actions 에서 아래 두 시크릿을 등록하면 이메일이 발송됩니다.

  • GMAIL_USER — 발신 Gmail 주소
  • GMAIL_APP_PASSWORD — Gmail 앱 비밀번호(16자리)
앱 비밀번호 발급 방법 →

예시

제품 가마솥, 지역 수원시로 등록하면 — 판매 위치가 수원이면서 제목에 가마솥이 포함된 새 매물이 올라올 때 지정한 이메일로 매물 정보와 당근마켓 구매 링크가 도착합니다.
